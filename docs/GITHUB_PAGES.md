# GitHub Pages — GuiaSys Memora

O frontend é estático e será publicado pelo GitHub Pages no domínio `https://memora.guiasys.online`.

## Primeira publicação

A primeira inicialização do repositório pode ser feita pelo GitHub Desktop.

## Atualizações seguintes

Depois que a pasta já possuir o repositório Git, use `PUBLICAR_GITHUB.bat` dentro de `guiasys-memora`. O arquivo solicita a mensagem do commit, executa `git add --all`, `git commit` e `git push`.

O arquivo `CNAME` deve permanecer no projeto para o domínio oficial continuar configurado no GitHub Pages.
