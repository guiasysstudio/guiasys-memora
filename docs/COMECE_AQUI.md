# GuiaSys Memora — Web

O frontend está preparado para `https://memora.guiasys.online` e Firebase Authentication.

## Autenticação

Disponível no código:

- Google;
- e-mail e senha;
- criação de conta;
- verificação de e-mail;
- recuperação de senha.

No Firebase Console, mantenha Google ativo e habilite também **Email/Senha**.

## API própria

A API ainda está desativada no frontend. Enquanto isso, criação de álbuns e mídia funcionam em modo demonstração. O projeto irmão `memora-server` contém a fundação da API própria que será instalada no servidor físico.
