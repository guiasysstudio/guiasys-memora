# Etapa atual — Login completo e preparação do servidor

Nesta versão:

- Google continua funcionando pelo Firebase Authentication;
- login por e-mail e senha foi adicionado;
- criação de conta por e-mail;
- envio de verificação de e-mail;
- recuperação de senha;
- tela de conta e saída;
- GitHub pode ser publicado pelo arquivo `PUBLICAR_GITHUB.bat` depois da primeira inicialização do repositório;
- o frontend ainda permanece em modo demonstração para álbuns e mídias enquanto a API própria não está publicada.

Para ativar e-mail/senha, habilite o provedor **Email/Senha** no Firebase Console > Authentication > Sign-in method.
