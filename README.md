# GuiaSys Memora

Frontend reconstruído do Memora para GitHub Pages + Firebase Authentication + futura API própria.

## Estado atual

- Domínio oficial: https://memora.guiasys.online
- Firebase: projeto `guiasys-memora`
- Login: Google
- Firebase Storage: não utilizado
- Frontend: GitHub Pages
- Fotos/vídeos: futuramente no servidor físico via API HTTPS
- Banco: futuramente PostgreSQL no servidor

A aplicação continua em modo demonstração até a URL da API própria ser configurada.

Consulte `docs/ETAPA_ATUAL.md` para o próximo passo.
